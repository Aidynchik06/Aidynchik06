# EduRobotKZ — Білім беру робототехникасы

Интеллектуалды электронды оқу құралы (Практикалық тапсырма, 13-апта).

## Модульдер

1. **Басты бет** — атауы, мақсаты, навигация
2. **Теория** — 4 тақырып (кіріспе, құрылғылар, Python, педагогика)
3. **Практика** — 3 Python тапсырмасы (шешімдерімен)
4. **Интеллектуалды тест** — 10 сұрақ, автоматты тексеру
5. **ЖИ Көмекші** — RoboMentor чат-бот
6. **Білімді бағалау** — нәтиже, талдау, ұсыныстар

## Технологиялар

- HTML5 · CSS3 · JavaScript (vanilla)
- 3D sci-fi фон, анимациялар, градиент мәтіндер
- Python мысалдары (gpiozero, pyfirmata)

## Қалай ашу

Браузерде `index.html` файлын ашыңыз немесе GitHub Pages арқылы қараңыз.

## GitHub Pages

Репозиторий → **Settings** → **Pages** → Source: **Deploy from a branch** → Branch: `main` → Folder: `/ (root)` → Save.
