Python арқылы роботтарды бағдарламалау

Python — робототехникада ең танымал тілдердің бірі. Оның қарапайым синтаксисі мен бай кітапханалары бастауыштан кәсіби деңгейге дейін қолданылады.

Python • Arduino серво басқару (pyFirmata) 
from pyfirmata import Arduino, util
import time

board = Arduino('COM3')  # Портты өзгертіңіз
servo = board.get_pin('d:9:s')  # 9-пин, серво

def wave():
    for angle in range(0, 180, 5):
        servo.write(angle)
        time.sleep(0.05)
    for angle in range(180, 0, -5):
        servo.write(angle)
        time.sleep(0.05)

while True:
    wave()
    time.sleep(1)
Python • Ультрадыбыстық сенсормен қашықтық 
import RPi.GPIO as GPIO
import time

TRIG = 23
ECHO = 24

GPIO.setmode(GPIO.BCM)
GPIO.setup(TRIG, GPIO.OUT)
GPIO.setup(ECHO, GPIO.IN)

def get_distance():
    GPIO.output(TRIG, True)
    time.sleep(0.00001)
    GPIO.output(TRIG, False)

    while GPIO.input(ECHO) == 0:
        start = time.time()
    while GPIO.input(ECHO) == 1:
        end = time.time()

    distance = (end - start) * 17150
    return round(distance, 2)

print("Қашықтық:", get_distance(), "см")

03 / ПРАКТИКА

Практикалық тапсырмалар

Python және робототехника бойынша 3 негізгі жаттығу

01 Оңай

Жеңіл қозғалыс роботы

Arduino немесе micro:bit негізінде алға-артқа қозғалатын қарапайым робот құрастырыңыз және Python арқылы басқарңыз.

45–60 мин 2 мотор + драйвер

Тапсырмалар:

  1. Шассиді құрастыру (2 дөңгелек + 1 тірек)
  2. Мотор драйверін қосу (L298N немесе аналогы)
  3. Python-да forward(), backward(), stop() функцияларын жазу
  4. Циклде қозғалыс үлгісін жасау
from gpiozero import Robot
from time import sleep

robot = Robot(left=(4, 14), right=(17, 18))

def forward(sec=2):
    robot.forward()
    sleep(sec)
    robot.stop()

def backward(sec=2):
    robot.backward()
    sleep(sec)
    robot.stop()

# Негізгі цикл
while True:
    forward(3)
    sleep(0.5)
    backward(2)
    sleep(1)
02 Орташа

Кедергіні анықтайтын робот

Ультрадыбыстық сенсор қосып, алдындағы кедергіні анықтап, бұрылатын робот жасаңыз.

90 мин HC-SR04 + 2 мотор

Тапсырмалар:

  1. HC-SR04 сенсорын қосу және қашықтықты өлшеу
  2. Егер қашықтық < 20 см болса — тоқтау
  3. Кездейсоқ бағытта бұрылу (солға/оңға)
  4. Логиканы циклге салу
from gpiozero import Robot, DistanceSensor
from time import sleep
import random

robot = Robot(left=(4, 14), right=(17, 18))
sensor = DistanceSensor(echo=24, trigger=23)

while True:
    dist = sensor.distance * 100  # см
    print(f"Қашықтық: {dist:.1f} см")
    
    if dist < 20:
        robot.stop()
        sleep(0.3)
        if random.choice([True, False]):
            robot.left(0.5)
        else:
            robot.right(0.5)
        sleep(0.8)
        robot.stop()
    else:
        robot.forward(0.6)
    sleep(0.1)
03 Қиын

Сызық бойымен жүретін робот

IR сенсорлар арқылы қара сызықты анықтап, оны бойлай қозғалатын робот құрастырыңыз (Line Follower).

2–3 сағат 2–3 IR сенсор

Тапсырмалар:

  1. 2 немесе 3 IR сенсорды шассиге орнату
  2. Сенсор мәндерін оқу (0/1 немесе аналог)
  3. PID немесе қарапайым if-else логикасын жазу
  4. Сызықтан шыққанда түзету алгоритмі
from gpiozero import Robot, LineSensor
from time import sleep

robot = Robot(left=(4, 14), right=(17, 18))
left_sensor = LineSensor(27)
right_sensor = LineSensor(22)

while True:
    left = left_sensor.value   # 0 = ақ, 1 = қара (түзетіңіз)
    right = right_sensor.value

    if left == 0 and right == 0:
        robot.forward(0.5)
    elif left == 1 and right == 0:
        robot.left(0.4)      # солға түзету
    elif left == 0 and right == 1:
        robot.right(0.4)     # оңға түзету
    else:
        robot.stop()         # екі жағынан да қара
    sleep(0.05)
